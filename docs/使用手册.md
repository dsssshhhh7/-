# 使用手册

## 命名规则

一个任务只处理“一个需求 + 一个端”。代号使用：

```text
<需求号>-<端>
```

例如：

```text
RM316-总控
RM316-Java
RM316-PHP
RM316-安卓
RM141-Java
RM141-安卓
```

多个需求并行时不要使用全局“Java”“安卓”代号，否则无法精准路由。

## 点对点传话

在 Java 项目中新建任务：

```text
代号叫 RM316-Java。当前只处理 RM316，负责 Java+React。
```

在 Android 项目中新建任务：

```text
代号叫 RM316-安卓。当前只处理 RM316，负责 Android。
```

直接发送：

```text
传给 RM316-安卓：请确认 RM316 的客户类型字段当前如何处理并回复。
```

不需要 `/team join`。显式写法是：

```text
/team say RM316-安卓 请确认 RM316 的客户类型字段当前如何处理并回复。
```

接收方先向当前窗口呈现原话。接收方可以自动回复一次，回复消息不再自动回复，防止两个任务无限循环。

## 多端讨论：手动创建任务

### 1. 建立总控

在 Full 项目新建任务：

```text
代号叫 RM316-总控。
为 RM316 建立多端讨论组，参与端为 Java+React、PHP、安卓。
先整理需求材料和初始方向，等我确认后再放各端加入。
```

也可以显式输入：

```text
/team join RM316
```

### 2. 人确认方向

总控必须把初始方向给人看。人确认后说：

```text
方向确认，讨论组设为就绪，可以让各端加入。
```

### 3. 各端加入

分别在对应项目新建任务，先登记唯一代号，再加入：

```text
代号叫 RM316-Java。负责 RM316 的 Java+React。
/team join RM316
```

```text
代号叫 RM316-PHP。负责 RM316 的 PHP。
/team join RM316
```

```text
代号叫 RM316-安卓。负责 RM316 的 Android。
/team join RM316
```

加入后会读取当前共识、材料、成员和已有约定，这就是自动补课。

### 4. 发起讨论

```text
同步给全组：请各端检查本端影响范围、依赖和交接点。
```

或：

```text
/team tell 请各端检查本端影响范围、依赖和交接点。
```

组内消息保存完整流水和处理回执。只有改变跨端契约、分工、依赖或需要另一端继续工作的信息才自动同步；本端调试日志和未核实猜测不广播。

### 5. 拍板与开发

需要人决定时，各端停止 AI 往返，由总控集中提问。人确认后再写入共识。

```text
方案确认，通知各端按分工开发。不要推送或部署，完成后回组报告。
```

推送、部署、删除等权限不会因为另一个任务发消息而自动扩大，仍以各任务中人的明确授权为准。

### 6. 结案

```text
/team close RM316
```

结案不可逆，执行前必须再次让人确认。完成后生成唯一结案文档并关闭活动组。

## 多端讨论：Full 自动创建任务

`/team join` 不会自动创建其他端。必须明确要求总控创建真实项目任务：

```text
为 RM316 启动多端协作。

参与端：Java+React、PHP、安卓。

先建立 RM316 讨论组并让我确认初始方向。确认后，请在 ai_dev_java、ai_dev_php、XbTerminal_waiqin 对应的真实 Codex 项目中创建任务，代号分别为 RM316-Java、RM316-PHP、RM316-安卓，让它们加入 RM316、自动补课并讨论。

禁止创建 projectless 任务。创建后检查每个任务的 projectId 和工作目录。当前先分析，不开发。
```

如果希望直接使用项目主目录，加一句：

```text
和我手动在项目里创建任务一样，使用 local 项目目录。
```

如果准备并行开发，加一句：

```text
各开发任务使用隔离 worktree，但仍必须归属于对应 Codex 项目。
```

## 常用命令

| 命令 | 作用 |
|---|---|
| `/team name <代号>` | 登记当前任务代号 |
| `/team say <代号> <内容>` | 点对点传话 |
| `/team book` | 查看地址簿和在线情况 |
| `/team join <组名>` | 当前任务创建或加入组 |
| `/team tell <内容>` | 向组内发送消息 |
| `/team who` | 查看成员和待处理数量 |
| `/team inbox` | 查看未处理消息 |
| `/team catch` | 读取当前共识和成员 |
| `/team log` | 查看组流水 |
| `/team ack` | 写入处理回执 |
| `/team leave` | 退出组 |
| `/team close` | 人确认后结案 |
| `/team doctor` | 检查插件和账本状态 |
