# 多会话协作 · 快速上手

多个 Claude Code 会话之间自动传话。**你只在最开始提要求和最后拍板时出现**，中间的来回不用你复制粘贴。

> 想知道它是什么、为什么这么设计、有哪些坑 → 看 `详细说明.md`

---

## 一、装

**不用手工拷文件**，它是一个插件，由公司 git 仓库统一分发、自动更新。

**多数人**：clone 下 ai_dev_full，**cd 进去**开一次 claude（会问一句信不信任这个目录，点一下），剩下全自动。

```bash
git clone https://git.xbwq.com.cn/waiqin/ai_dev_full.git
```

⚠️ **必须在 ai_dev_full 目录下开会话才会触发安装**。装好之后，**任意工程目录**都能用 `/team`。

**从不碰 ai_dev_full 的人**：手敲两条，一辈子一次。

```bash
claude plugin marketplace add https://git.xbwq.com.cn/waiqin/ai_dev_full.git
claude plugin install team@xbcx --scope user
```

**确认装好了**：新开会话敲 `/team doctor`，它会体检并告诉你哪里不对、怎么修。

**前提**：macOS 或 Windows（Windows 需装 Git Bash）、装了 `jq`、git 能连上公司服务器。

## 二、开窗口时你会看到什么

**不用敲命令、也不用先说话**，它自己就报一次：

```
📋 协作现状

讨论组（共 2 个）
  组名                      人数  未读  最后活动      我在吗
  ────────────────────────────────────────────────────────
  外勤-定位上报改造          4     3     08-17 09:12   ✅ 代号 android
  RM-209                    3     —     08-16 22:10   —

我所在的组，同组还有谁
  组名                      同组成员
  ────────────────────────────────────────────────────────
  外勤-定位上报改造          iOS · php · java+react

同是【android】的其他会话
  代号         工作目录                                 在哪些组   未读  会话编号
  ──────────────────────────────────────────────────────────────────────────
  android-排查 ~/Documents/waiqin_android.worktrees/abc  RM-209    2     7363598a-…（完整）
```

| 这一块 | 回答什么 |
|---|---|
| **讨论组** | 机器上正在进行哪些事、我在不在里面 |
| **同组还有谁** | 该找谁对齐 |
| **同是【X】的其他会话** | **还有哪些窗口跟我是同一个端**——防止同一件事被两个安卓窗口各做一遍 |

「未读」= 对方手上还压着几条没处理。「同一个端」按 **git 仓库地址**认，跟目录名无关，所以 worktree、换机器、改目录名都认得出。

刚自动更新过的话，上面还会多一行 `🔧 协作插件已更新：X → Y`。

### 状态栏上那一块：这个窗口是谁

装一次之后，输入框下面那条状态栏末尾会一直挂着这个窗口的代号：

```
[Opus 5] │ waiqin_full git:(master) │ 安卓
Context ██░░░░░░░░ 16% │ Usage ░░░░░░░░░░ 3% ...
```

切到哪个窗口，一眼就知道它在协作里是谁 —— 开四五个窗口的时候，这比每次敲 `/team me` 去问快得多。

- 没登记过代号的窗口显示 **代号未登记**（留空的话，你分不出是"这窗口没进协作"还是"状态栏坏了"）
- 代号后面带 **问号**（`总控?`）= 连这个窗口的编号都没拿到，只能按工作目录猜。正常装法下不会出现；出现了说明状态栏没走 `/team statusline` 装的那个入口
- **编号拿到了、但这个窗口没登记过 → 一律显示「代号未登记」**，绝不拿同目录下别的窗口的代号顶上
- 装法：`/team statusline`，它会保存你原来的状态栏、告诉你 `settings.json` 要改哪一行。改完**重开一个窗口**才生效
- **装了插件不会自动生效** —— 状态栏是你自己 `settings.json` 里的配置，插件没有接管它的口子。所以只要还没挂上，开窗口时会提一行问你要不要挂；说「挂上代号」就装，说「状态栏不用了」就以后不再提。挂上之后这行提示自动消失
- 插件哪天不在了，状态栏会自动退回你原来那条，不会变空

## 二点五、传话台：不用建组，直接把话传给另一个窗口

**讨论组是给"一件事要几方一起定"用的，传话台是给"我要把这句话准确送到某个窗口"用的。**两套东西，互不打扰。

```
你：代号叫 安卓                    ← 每个端第一次，一句话
你：传给 iOS：定位字段先按老口径走，等 PHP 那边确认再改
   ✅ 已送到【iOS】（在线）
```

- **不用建组、不用拉人、不用加入** —— 登记了代号就能收发
- **发之前自动查对方在不在线**。不在线**默认不发**，告诉你它离线多久，给三条路：等它 / 找回它 / 改发给别人。（往关着的窗口发消息**不会报错**，消息会一直躺在信箱里没人看 —— 你会以为传到了）
- **对方可以自动回一条**，回完就到此为止；要继续得你重新起头。防的是两个窗口自己聊起来
- **谁在线**：`/team who`（不带组名）= 地址簿，列出所有窗口、在线还是离线、离线多久
- **全程留痕**：`~/claude-team/传话台/传话记录.md`，谁给谁发了什么、全文照录、当天固定这个文件名，隔天自动改名归档，默认留 7 天（每台机器可自己配）

**传话台对外是看不见的**：`/team groups`、`/team who <组名>`、开窗口的协作现状里都不会出现它 —— 它压根不是组。

> 🚨 **给会话的一条硬规矩**：收到传话**不等于**收到任务。它是"人让我把这句话带给你"，
> 会话只负责原样摆到你面前，**要不要动手由你说**。

## 三、用

四个会话做同一个需求，每个窗口敲一次：

```
/team join 外勤-定位上报改造
```

它会问你这个会话叫什么、负责哪块。之后：

```
/team tell 上报接口字段确定：lat 改名为 latitude
```

三端 5 秒内各自被叫醒，自己去改自己的，**你一个字没打**。

> **别记这些也行**，直接说人话："把这个结论同步给另外两端"、"看看谁还在线"、"这个需求做完了，结案吧"——效果一样。中文命令也认：`/team join xxx`、`/team who`、`/team tell xxx`。

### 日常最常用

| 敲这个 | 干什么 |
|---|---|
| `/team` | 我现在什么状态、有哪些组 |
| `/team join <组名>` | 加入（组不存在就建） |
| `/team who` | 组里有谁、谁在线、各压着几条未读 |
| `/team tell <内容>` | 发给全组 |
| `/team inbox` | 看有什么没处理 |
| `/team pin <结论>` | 把一条结论写进共识 |
| `/team catch` | 补课，重读当前约定 |
| `/team log` | 传话流水：谁什么时候跟谁说了什么 |
| `/team ack` | 回执：谁收到了、谁真处理了 |
| `/team leave` | 退出协作 |
| `/team close` | 需求上线了，结案 |
| `/team doctor` | 体检 |

### 建组的人还会用到

新建的组默认「准备中」，**别人进不来**——要先把方向跟人谈定、过完六道门槛。

| 敲这个 | 干什么 |
|---|---|
| `/team status` | 这个组还差什么才能放人进来 |
| `/team material <内容>` | 登记原始材料在哪（**最前置**） |
| `/team think` | 按 12 个角度挖「该定而没定」的点，逐条问人 |
| `/team ready` | 推到「就绪」（**要人点头**） |
| `/team claim <内容>` | 认领一件待拍板的事，防两个端同时去问同一个人 |

### 偶尔用到

| 敲这个 | 干什么 |
|---|---|
| `/team resume <代号>` | 找回关掉的会话 |
| `/team clean` | 清理没主的后台进程和卡住的锁 |
| `/team watch smart｜off` | 开/关加工员（**唯一花钱的那层**，默认关） |
| `/team index` | 共识长了以后，找出该连读的条目 |
| `/team statusline` | 把代号挂到状态栏上（装一次就行，见上面第二节） |
| `/team name <名字>` | 给这个窗口起个代号或改名。**不用先加入任何组**，退出全部组之后代号也留着 |
| `/team say <代号> <内容>` | 传话台：把一句话点对点送到另一个窗口（见上面第二点五节） |
| `/team who`（不带组名） | 地址簿：谁在线、谁离线多久、在哪些组 |
| `/team sync` | 顺带列出「不在任何组 + 长期没动静」的在册记录，问你要不要清 |

## 四、出问题先看这里

| 现象 | 多半是 |
|---|---|
| 新开窗口没看到协作现状 | 那个窗口开在插件更新之前。**重开一次** |
| 一直提醒"收件程序不在岗" | 你在组里但没起收件程序。让会话起一个，或 `/team leave` 退出该组 |
| 发了消息对方没反应 | 对方窗口关了。消息不丢，它重开就收 |
| 回执显示 `··`（没送达） | 对方没开机；或者组文件当时被占用，下次跑 `/team ack` 会自动补上 |
| 命令报"只能在 Claude Code 会话里运行" | 你在普通终端里敲了。这些命令要靠会话带的编号认人 |
| 状态栏上没有代号那一块 | ① 还没挂：`/team statusline`；② 挂了但没重开窗口 —— 状态栏配置是开窗口时读的 |
| 状态栏显示「代号未登记」 | 这个窗口还没起过代号：`/team name <名字>`。**不用先进组** |
| 状态栏显示的代号后面带问号 | 连这个窗口的编号都没拿到，只能按目录猜。多半是状态栏没走 `/team statusline` 装的那个入口 |
| 状态栏整条空了 | 入口或底座被删了。还原：把 `settings.json` 的 `statusLine` 换回 `~/claude-team/.statusline/original-statusline.txt` 里那行 |
| 状态栏上的代号忽然没了 | 多半是重跑过 claude-hud 的 setup，它把 `statusLine` 改回自己那条了。再敲一次 `/team statusline` |
| 起代号报"被一个已经关掉的窗口占着" | 那个名字挂在一条死记录上。**它还在讨论组里就一定不给** —— 得把那个窗口找回来、把欠账处理完、退组、关掉。它不在任何组、又离线了，才能顶掉 |
| 传话说"对方不在线"发不出去 | 那个窗口的收件程序没在跑（关了，或开着但没起）。等它 / `/team resume <代号>` 找回它 / 改发别人；确实要留着让它下次看，说一句"留言" |
| 传话回复被拒"已经回过一次了" | 传话台一来一回就到此为止 —— 这是防两个窗口自己聊起来。还有话说，由你重新起头 |
| 明明开着窗口却显示"离线" | 在线判据是收件程序的心跳。窗口开着但没起收件程序 = 离线（它本来也收不到消息）。让那个窗口起一个 |
| 传话台目录里冒出 `待入账/` | 那次写记录时抢锁失败了，这条被暂存下来 —— **消息本身已经发出去了**。下次再传一条它就自动补进正式记录、目录清空，不用管 |
| 别的说不清的毛病 | `/team doctor`，它每项都给可执行的修复命令 |

**兜底**：所有消息原文都在 `~/claude-team/` 的文件里躺着，机制整个挂掉也能手动去翻。

## 五、装在哪

| | 路径 | 内容 |
|---|---|---|
| 代码 | `~/.claude/plugins/cache/xbcx/team/<版本号>/` | 30 条指令 + 值班守则。**路径带版本号，每次更新都变** |
| 数据 | `~/claude-team/` | 索引、各组共识、信箱、结案文档、**传话台记录**。**首次使用自动创建** |
| 源码 | `ai_dev_full/plugins/team/` | 要改代码改这里，推上去所有人自动拿到 |

代码路径会变，**不要写死**。当前版本的真实路径永远记在 `~/claude-team/.插件检查/bin路径`。

用了传话台之后，数据目录下还会多这几样：

| 路径 | 内容 |
|---|---|
| `~/claude-team/传话台/传话记录.md` | 当天的传话全记录（谁给谁、为什么、正文全文）。**当日固定这个名字**，隔天自动改名成 `传话记录-日期.md`，默认留 7 天 |
| `~/claude-team/传话台/待入账/` | **平时不该有**。只有在写记录时抢锁失败才会临时出现，下次任何一次成功写入会自动补进正式记录并清空 |
| `~/claude-team/代号变更史.md` | 谁在什么时候顶掉/注销了哪个代号。**只追加不删** —— 事后回答「这个名字上周是谁」全靠它 |
| `~/claude-team/会话/<编号>/.beat` | 收件程序在岗时每一轮碰一下。**有这个文件且新鲜 = 在线** |
| `~/claude-team/会话/<编号>/.beat-last` | 收件程序正常下班时留下的「墓碑」。有它才分得清「关掉的窗口」和「从没接进来的窗口」，也才算得出离线了多久 |
| `~/claude-team/会话/<编号>/.replied/` | 哪条投递已经回过了（每条只能回一次）。**保留期跟传话记录同一个** —— 台账先没了的话，那条投递就又能回一次 |
| `~/claude-team/.plugin/config` | 这台机器自己的设置，第一次用自动生成、带注释。目前就一条 `talk_keep_days`（传话流水留几天，默认 7），改完立刻生效 |

> **机器用的那些文件一律英文名**（上面带点开头的都是）。它们要么被别的 shell 执行、要么被脚本反复拼接，
> 中文名在 Windows / 非 UTF-8 环境下容易出事。**人要读的东西全是中文**（会话索引、协作组、传话台、
> 共识、流水、结案文档）—— 那才是产品本身。老装机上的中文名开一次窗口自动搬过去，内容不丢。

挂了状态栏的话，还会多这几个（都在数据目录下，插件升级不影响）：

| 路径 | 内容 |
|---|---|
| `~/claude-team/statusline.sh` | 状态栏入口。`settings.json` 里**只填这一个路径**，插件升级不用改。**文件名故意用英文** —— 它要被别的 shell 执行，中文路径在 Windows 上会被转码吃掉 |
| `~/claude-team/.statusline/base.sh` | 你原来的状态栏命令，原样存着。代号那块挂在它后面显示；插件哪天不在了，入口自动退回来跑它 |
| `~/claude-team/.statusline/original-statusline.txt` | 同上，纯文本一行，**还原时照它改回去** |
| `~/claude-team/.statusline/disabled` | 你说过"状态栏不用了"就有这个文件，开窗口时不再提。想装了跑一次 `/team statusline` 会自动去掉 |

## 六、改代码的人注意（踩过的坑）

- **macOS 自带 bash 是 3.2**，`$变量` 紧跟中文会把中文字节当变量名——**一律写 `${变量}`**
- **中文占两格**，`printf %-20s` 按字符数补空格必然错位——用 `t_pad`
- **带 `case` 的 while 循环别放进 `$( )`**，bash 3.2 会报语法错并把源码打出来
- **人看不到钩子的正常输出**，只看得到"钩子失败"。要让人看见得走 `systemMessage`
- **`stat` / `date` 先试 GNU 写法**：Git Bash 上 `stat -f` 会把格式串当文件名
- **收件箱为空时用通配符 `*.md` 会崩**（zsh 的 nomatch），必须用 `find`
- **`awk` 的位置语义两边不一样**：macOS 自带的按**字节**算，Windows 的 gawk 按**字符**算。对中文做 `substr` / `index` 算术，两边结果不同 —— 用正则删头删尾，别用下标
- **别用 `python3`**：公司 Windows 上它是应用商店占位程序，什么都不做就退出，于是那段逻辑**静默失效**，还会报成功。这个坑踩过两次，现在全仓一处都没有
- **先查后写不是锁**：`while [ -e "$f" ]` 挑不重名的文件名，两个进程会同时挑中同一个。要原子性就用 `set -o noclobber` 那圈写法
- **拿锁分两步就有空隙**：先建目录、再写时间戳，别人正好在空隙里读会读到空值。判死锁时读不到时间戳要退回看目录自己的创建时间，否则会把别人**正拿着**的锁删掉
- **机器用的文件一律英文名**（`.beat`、`.plugin/binpath`、`.statusline/base.sh` 这些）。人要读的中文文件不要动。改名要在 `t_migrate_paths` 里加一行，并想清楚**过渡期别的窗口还跑着旧版本**会怎样
- **改了 `plugins/team/` 下任何东西，必须同时把 `plugin.json` 版本号 +1**，否则别人永远拉不到更新**而且不报任何错**
- **验收前先确认对方窗口跑的是哪一版**：会话找命令用的位置记录只在开窗口时刷新，老窗口会一直跑旧代码 —— 很容易「改完让另一个窗口去验，验的其实是旧版本」
